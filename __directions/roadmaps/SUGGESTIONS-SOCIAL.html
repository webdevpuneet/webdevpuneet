How to use this

Each idea has a status: Suggested (not started), Building (in progress) or Done (shipped, kept here as a record). Newest first inside each group.

Rule for what gets added: an idea goes here only if it fills a real gap (something visitors look for that the site does not have, or a workaround a current template forces). Ideas for other areas live in their own files; start from the Suggestions index.

Design and animation bar for every new template (decided 2026-11-02):

  • Creative, great-looking design: its own layout and a clear idea, not a recolour of an existing template. Check it at every post size (square, portrait, Story with its safe areas) and with long and short text.
  • Built to animate on export: the video export (MP4 / WebM, in render.js) animates every [data-edit] text slot and [data-image] photo in reading order (rise, fade or pop). Anything meant to animate must be one of those slots, and the slots must be ordered so the reveal reads well (headline, then detail, then the call to action). Decorative shapes are not animated today.
  • Check the video: export the animated video once per new template and watch it before calling the template done.

Idea to make exports feel richer: let a template mark decorative parts as animatable (a data-anim hook) so shapes, badges, ratings and bars move too: stars filling, a progress bar growing, numbers counting up, a countdown ticking, underlines drawing. Countdown, 5-star review, big stat, flash sale and pricing card would benefit first.

Rule for every new social post template: animate each part in a way that fits its theme (decided 2026-11-02). Not a generic fade on everything: each moving part should do what that thing would do in real life. A flame flickers, a heart beats, a tick gets stamped, a number counts up.

  • How to build it: a decorative part is a real element with data-anim="<motion>" (see render.js). Motions that exist today: flicker (flames), float (hearts: drift and heartbeat), tick (pop in with overshoot, one after another), drift (confetti: slow wander). Add a new motion only when none fits, and reuse it afterwards.
  • Built so far: Diwali (flickering diya flames), Valentine's Day (drifting, beating hearts), Pricing Card (ticks pop in), Thank You (floating confetti).
  • Check each one: press Play in the editor, watch the whole loop at phone size, and confirm that nothing is clipped, nothing leaves its place for good and the post settles back to normal.

WhatsApp sharing (added 2026-11-02):

  • Works today: download the PNG or JPG and send it in a chat, a group or a Channel, or post the Story size (1080×1920) as a WhatsApp Status. WhatsApp compresses photos, so for crisp text send the file as a document.
  • Share button (idea): a "Share" item in the Export menu that opens the phone's share sheet with the image attached (the Web Share API with files), so WhatsApp is two taps away on a phone without saving to the gallery first. Falls back to a download on desktop.
  • Video for Status: WhatsApp plays MP4 but not WebM, and Status videos are limited to about 30 seconds. The animated export is MP4 in Chrome (6 seconds by default), so it fits; show a note when the browser can only make WebM.
  • Size note: a "WhatsApp Status" label on the Story size in the size picker, since many users in India look for it by that name.

For each template: curated, polished, non-generic SEO text (written for that one template, never a pattern with the name swapped; see 06-QUALITY-BARS.txt) within the length limits, preview image, category page entry, sitemap and llms.txt.
