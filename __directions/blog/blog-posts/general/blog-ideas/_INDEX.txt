HOW THIS WORKS
--------------
Each topic file (CSS.txt, GSAP.txt, JavaScript.txt, React.txt, UX.txt) holds a
priority-ordered queue of final post titles. Publish top-down.

After writing a post:
  1. Change  [ ]  to  [x]  on that line
  2. Append  -> general-blogNN.txt
  3. Add the same line to the PUBLISHED list below

Marking convention:
  [ ]  not written yet
  [x]  published
  [~]  partially covered elsewhere — only write as a deeper dive (see note on line)

CROSS-FILE DEDUP RULES

do not write the same build twice under a different framing:

  Multi-step form ............... vanilla in JavaScript.txt / React in React.txt
