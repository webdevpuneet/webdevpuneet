__DIRECTIONS — the planning home of webdevpuneet.com
Created 2026-10-28. Owner: Puneet Sharma. Advisor: Claude (see 04-DAILY-ADVISOR-PLAYBOOK.txt).

WHAT THIS FOLDER IS
  Every idea, direction, roadmap, rule and log for webdevpuneet.com lives here, so any
  session (human or AI) can open one folder and know where the project is going and why.
  It is not deployed (it is outside public/ and out/).

READ IN THIS ORDER
  01-VISION-AND-POSITIONING.txt   why the site exists, who it is for, how we sit next to AI
  02-PRODUCT-AREAS.txt            each part of the site: what it is, where it lives, quality bar, next ideas
  03-LEADS-HIRE-ME.txt            how every template, tool and page turns interest into Hire Me leads (/puneet/)
  04-DAILY-ADVISOR-PLAYBOOK.txt   how "what can we do today?" is answered, across the whole project lifecycle
  05-ADVISOR-LOG.txt              dated log of advice given and what was done (newest first)
  06-QUALITY-BARS.txt             the A-grade checklists: SEO, accessibility, performance, templates, workflow rules

  - A new idea: add it to roadmaps/SUGGESTIONS.html (root copy) and mention it in 05-ADVISOR-LOG.txt.
  - A new rule: add it to 06-QUALITY-BARS.txt.
  - A change of direction: edit 01 or 02 and write one dated line in 05-ADVISOR-LOG.txt.
