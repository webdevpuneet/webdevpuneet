<h2>What actually makes a hero section work</h2>

<p>Before picking a style, it helps to know what a hero is actually for. Regardless of which of the eight below you choose, every good hero does three things in the first two seconds:</p>

<ul>
<li><strong>States the value proposition in one glance</strong> — the headline should answer "what is this and why should I care" without requiring the visitor to read the subheading.</li>
<li><strong>Establishes credibility fast</strong> — a stat row, an avatar stack, a client logo strip, or a star rating does more trust-building work in that first glance than another paragraph of copy.</li>
<li><strong>Points to exactly one next action</strong> — a single primary CTA, not three competing buttons. Secondary actions (watch a demo, view work) should visually defer to it.</li>
</ul>

<p>Keep that checklist in mind as you scroll — every snippet below already implements at least two of the three, and you can borrow pieces across styles.</p>

<h2>5. Word Flip Hero</h2>

<p>A single word in the headline cycles vertically through several alternatives — "Build Faster / Smarter / Better / Together" — communicating product versatility in one sentence instead of a paragraph.</p>

<iframe src="https://fwdtools.com/ui-snippets/word-flip-hero/embed/" style="width:100%;height:480px;border:0;border-radius:10px;overflow:hidden;" loading="lazy" title="Word Flip Hero — Free HTML/CSS/JS Snippet by FWD Tools"></iframe>

<p><strong>How it works:</strong> every word sits stacked in a vertical flex column inside a container clipped to exactly one line's height with <code>overflow: hidden</code>. JavaScript measures a single word's real pixel height at runtime and sets <code>translateY(-index × height)</code> on the column to slide the visible window to the current word — so unlike a fixed-duration CSS keyframe, it works correctly with words of any length, and adding a new word to the cycle is a pure HTML change. The cycling words also carry a gradient text fill that matches the CTA buttons for visual coherence.</p>

<p><strong>Best for:</strong> SaaS and startup landing pages, portfolio headlines that address multiple client types, and agency homepages spanning several service lines. <strong>Tip:</strong> the <code>flip-wrap</code> element carries <code>aria-live="polite"</code>, so screen readers announce each new word after it transitions in — don't strip that attribute if you customize the markup.</p>

<h2>Keep your hero fast and accessible</h2>

<p>A hero that looks great but tanks your Lighthouse score or excludes users isn't doing its job. Three rules cover almost every case:</p>

<ul>
<li>Animate only <code>transform</code>, <code>opacity</code>, and CSS custom properties — anything that triggers layout or paint on every frame (like animating <code>width</code> or <code>top</code> directly) will jank on lower-end devices.</li>
<li>Respect <code>prefers-reduced-motion</code> — wrap drifting blobs, shimmer sweeps, and cycling words in a media query that freezes them for users who've asked for less motion, without removing the visual design.</li>
<li>Keep the headline as real, selectable text — gradient and shimmer effects should use <code>background-clip: text</code> on genuine text nodes, never a background image standing in for the words, so screen readers and copy-paste both still work.</li>
</ul>
