<h2>What these ten get right</h2>

<ul>
<li><strong>Native browser APIs before reaching for a library.</strong> The kanban board's drag-and-drop is the actual HTML5 Drag and Drop API — <code>draggable="true"</code> plus <code>dragstart</code>/<code>dragover</code>/<code>drop</code> listeners — with the one line (<code>e.preventDefault()</code> inside <code>dragover</code>) that's easy to leave out and that silently breaks every drop if you do.</li>
<li><strong>Sorting the real value, not the formatted text.</strong> The data table's columns each carry a <code>data-type</code> of <code>text</code>, <code>num</code>, or <code>date</code>, and a per-type getter reads each row's raw, unformatted data attribute before comparing — so sorting "Total spent" actually orders by the number, not by a currency string that would silently sort wrong.</li>
<li><strong>State recalculated from the DOM, not tracked in a separate variable.</strong> The kanban board's per-column counts and the notification dropdown's unread badge are both recomputed by reading what's actually in the DOM after every change, rather than incrementing or decrementing a number that could drift from reality.</li>
<li><strong>Cleanup that actually happens.</strong> Bootstrap's Toast component hides a dismissed toast but never removes its element — this collection's toast stack listens for the real <code>hidden.bs.toast</code> event and removes the node only once the hide animation has genuinely finished, so triggering dozens of toasts in a session never leaks stale elements.</li>
<li><strong>One Bootstrap instance, reused correctly.</strong> The lightbox gallery uses a single real Bootstrap modal for all six images, opened to whichever thumbnail was clicked via a shared index — not six separate modal elements — and the notification dropdown's <code>data-bs-auto-close="outside"</code> keeps the panel open across several clicks instead of Bootstrap's default of closing it on the very first one.</li>
</ul>

<h2>7. Bootstrap Kanban Board with Drag-and-Drop Cards</h2>

<p>A real Bootstrap kanban board where cards genuinely drag between columns using the browser's native HTML5 Drag and Drop API, with a live per-column count.</p>

<iframe src="https://fwdtools.com/ui-snippets/bootstrap-kanban-board-cards/embed/" style="width:100%;height:560px;border:0;border-radius:10px;overflow:hidden;" loading="lazy" title="Bootstrap Kanban Board with Drag-and-Drop Cards — Free HTML CSS JS Snippet by FWD Tools"></iframe>

<p><strong>How it works:</strong> every card carries <code>draggable="true"</code>, and the board is wired with genuine <code>dragstart</code>/<code>dragend</code>/<code>dragover</code>/<code>drop</code> listeners — no third-party drag library. The one line that's easy to leave out: a drop zone's <code>dragover</code> handler must call <code>e.preventDefault()</code>, because browsers reject drops everywhere by default — without it, the <code>drop</code> event simply never fires, no matter how the card is released. Dropping itself is one line, <code>zone.appendChild(dragged)</code>, and a shared <code>updateCounts()</code> re-reads how many cards each column actually contains after every drag ends, so the badges can never go stale.</p>

<p><strong>Best for:</strong> internal tools and lightweight project trackers needing the standard To Do / In Progress / Done pattern without a drag-and-drop dependency. <strong>Tip:</strong> relabel the three columns for a sales or hiring pipeline — the drag/drop logic doesn't care what the columns are called.</p>

<p>A real Bootstrap table where clicking any column header sorts by that column's actual data type — text, number, or date — rather than by the formatted text on screen.</p>

<iframe src="https://fwdtools.com/ui-snippets/bootstrap-sortable-data-table/embed/" style="width:100%;height:460px;border:0;border-radius:10px;overflow:hidden;" loading="lazy" title="Bootstrap Data Table with Sortable Columns — Free HTML CSS JS Snippet by FWD Tools"></iframe>

<p><strong>How it works:</strong> sorting the visible <code>$3,120</code> text as a plain string breaks the moment currency formatting or a non-ISO date enters the picture. Every row instead carries its raw, unformatted value in a data attribute, and a per-type <code>GETTERS</code> object — <code>Number()</code> for numeric columns, <code>new Date().getTime()</code> for the date column — converts it correctly before comparing. <p><strong>Best for:</strong> admin dashboards and any table of records past a handful of rows, where sortable columns are close to a baseline expectation. <strong>Tip:</strong> drop this straight into the Bootstrap admin dashboard's orders table from the first batch for a fully interactive records view.</p>

<h2>10. Bootstrap Toast Notification Stack</h2>

<p>Real Bootstrap toasts created on demand and stacked in the corner — each auto-dismisses after 4 seconds and removes itself from the DOM once its hide animation genuinely finishes.</p>

<iframe src="https://fwdtools.com/ui-snippets/bootstrap-toast-notification-stack/embed/" style="width:100%;height:420px;border:0;border-radius:10px;overflow:hidden;" loading="lazy" title="Bootstrap Toast Notification Stack — Free HTML CSS JS Snippet by FWD Tools"></iframe>

<p><strong>How it works:</strong> most Toast demos show one static example — this one builds what a real app actually needs, creating a fresh <code>&lt;div class="toast"&gt;</code> on every trigger click, appending it into a shared <code>.toast-container</code>, and handing it to a new <code>bootstrap.Toast</code> instance with a real 4-second <code>delay</code> option rather than a custom <code>setTimeout</code>. <p><strong>Best for:</strong> save confirmations and any background action feedback that shouldn't interrupt what someone's doing. <strong>Tip:</strong> wire one of the trigger types directly to a real <code>fetch()</code> call's success/error branches instead of a button click.</p>
