<h2>What these ten get right</h2>

<ul>
<li><strong>Two escaping passes, not one.</strong> The search-highlighting snippet escapes the result text for safe HTML injection <em>and</em> escapes the user's query before it's ever turned into a RegExp — skip either one and a user typing a regex-special character like <code>(</code> either breaks the search or opens an HTML-injection hole.</li>
<li><strong>A filtered index that can't point past its own list.</strong> The command palette re-clamps its highlighted <code>activeIndex</code> after every keystroke, so filtering down to two results while the fourth item was highlighted can never silently point at nothing.</li>
<li><strong>Real recursion, not a fixed two levels.</strong> The API response viewer's tree renderer calls itself for every nested object or array however deep, with each collapsible node getting its own unique id so collapsing one section never touches any other.</li>
<li><strong>Copy that actually falls back.</strong> The copy-to-clipboard and code-block snippets both try the modern <code>navigator.clipboard</code> API first and fall back to a working <code>document.execCommand('copy')</code> path outside a secure context or on a denied permission — and each button tracks its own "flashing" state independently.</li>
<li><strong>Real range math, not a hardcoded table.</strong> The HTTP status badge classifies any valid 3-digit code by numeric range, correctly coloring a code that never appears in its own reference list.</li>
</ul>

<h2>4. Bootstrap Search Results Highlighting</h2>

<p>A live search where the matching substring of every visible result is wrapped in a real <code>&lt;mark&gt;</code> — safely, even if you search for a character like <code>(</code> that means something different in regex.</p>

<iframe src="https://fwdtools.com/ui-snippets/bootstrap-search-results-highlighting/embed/" style="width:100%;height:440px;border:0;border-radius:10px;overflow:hidden;" loading="lazy" title="Bootstrap Search Results Highlighting — Free HTML CSS JS Snippet by FWD Tools"></iframe>

<p><strong>How it works:</strong> the query is escaped for safe use inside a <code>RegExp</code> before it's ever built into a pattern — without that, a user typing a regex-special character would either throw an error or match unpredictably. The result text is separately HTML-escaped before highlighting, so it can never be misinterpreted as markup. A capturing group in the replacement preserves the original text's exact casing, so searching "grid" still highlights "Grid" with its real capital G.</p>

<p><strong>Best for:</strong> documentation search, admin log viewers, and any filtered list where seeing exactly what matched speeds up scanning. <strong>Tip:</strong> both escaping passes are load-bearing — skip the regex one and a search for <code>*</code> throws; skip the HTML one and result text becomes an injection risk.</p>

<h2>5. Bootstrap Command Palette</h2>

<iframe src="https://fwdtools.com/ui-snippets/bootstrap-command-palette/embed/" style="width:100%;height:460px;border:0;border-radius:10px;overflow:hidden;" loading="lazy" title="Bootstrap Command Palette — Free HTML CSS JS Snippet by FWD Tools"></iframe>

<p><strong>How it works:</strong> a global <code>keydown</code> listener checks for <code>(e.ctrlKey || e.metaKey) &amp;&amp; e.key === 'k'</code> and funnels into the same <code>open()</code> function the visible button uses, resetting the query and highlight every time. Filtering and keyboard navigation share one <code>activeIndex</code>, re-clamped after every keystroke against the current filtered list's length — the single most common bug in a homemade command palette is skipping that clamp and letting the highlight point past the end of a shortened list.</p>

<p><strong>Best for:</strong> developer tools, internal admin panels, and any SaaS dashboard with more destinations than fit in a menu. <strong>Tip:</strong> pair with the keyboard shortcut help modal below to document every shortcut in one place.</p>

<p><strong>Best for:</strong> any app with more than a couple of custom keyboard shortcuts, especially one that already has a command palette worth documenting. <strong>Tip:</strong> generate the shortcut list from the same data structure that registers each shortcut's real handler, so the documented list and the actual behavior can never drift apart.</p>

<h2>7. Bootstrap Copy-to-Clipboard Feedback</h2>

<p>Two copy buttons — an API key and a referral link — each showing a genuine "Copied!" flash that reverts on its own, with a working fallback outside a secure context.</p>

<p><strong>Best for:</strong> API keys, tokens, referral links, and any short string a user needs to grab and paste elsewhere with unambiguous confirmation. <strong>Tip:</strong> the per-button busy guard matters the moment a page has more than one copy button — a shared flag would let one button's click interfere with another's.</p>
