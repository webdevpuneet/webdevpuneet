<h2>3. Bootstrap Paste-to-Upload (Clipboard Image Paste)</h2>

<p>Click the zone and press Ctrl+V to paste a screenshot directly from the clipboard — no file picker, with a genuine ClipboardEvent driving the whole thing.</p>

<iframe src="https://fwdtools.com/ui-snippets/bootstrap-paste-to-upload/embed/" style="width:100%;height:420px;border:0;border-radius:10px;overflow:hidden;" loading="lazy" title="Bootstrap Paste-to-Upload (Clipboard Image Paste) — Free HTML CSS JS Snippet by FWD Tools"></iframe>

<p><strong>How it works:</strong> the zone needs <code>tabindex="0"</code> to become genuinely focusable, which is a prerequisite for a <code>paste</code> event to ever fire on it at all. The listener reads <code>e.clipboardData.items</code> for the first entry whose type starts with <code>image/</code>, correctly ignoring plain copied text with an explicit message instead of failing silently. The previous object URL is revoked before a new one is created, so repeated pastes never leak memory.</p>

<p><strong>Best for:</strong> bug report forms and support tickets, where pasting a screenshot directly is dramatically faster than saving it to disk first. <strong>Tip:</strong> keep a traditional file input available as a fallback for mobile, where clipboard image paste support is far less consistent than on desktop.</p>

<h2>4. Bootstrap Duplicate File Detection on Upload</h2>

<p>Select a file that's already been added and it's silently skipped with a clear warning — matched by name, size, and modification time together, not just a filename.</p>

<iframe src="https://fwdtools.com/ui-snippets/bootstrap-duplicate-file-detection-upload/embed/" style="width:100%;height:420px;border:0;border-radius:10px;overflow:hidden;" loading="lazy" title="Bootstrap Duplicate File Detection on Upload — Free HTML CSS JS Snippet by FWD Tools"></iframe>

<p><strong>How it works:</strong> a signature combining a file's name, size, and <code>lastModified</code> timestamp is cheap to compute and specific enough to trust, without needing to hash every byte of every file client-side. Newly accepted files are added to the comparison set as they're processed within the same selection — without that, selecting the identical file twice in one multi-file dialog would let both copies through, since neither would exist in the list yet at comparison time.</p>

<p><strong>Best for:</strong> document attachment forms and bulk import tools where an operator might accidentally re-select something already queued. <strong>Tip:</strong> the warning names the exact files that were skipped, not a generic "duplicate detected" message.</p>

<h2>5. Bootstrap Image Crop Before Upload</h2>

<p>A real pan-and-zoom cropper — drag to reposition, a zoom slider, and a Save action that computes the exact visible crop back into full-resolution source pixels.</p>

<iframe src="https://fwdtools.com/ui-snippets/bootstrap-image-crop-before-upload/embed/" style="width:100%;height:460px;border:0;border-radius:10px;overflow:hidden;" loading="lazy" title="Bootstrap Image Crop Before Upload — Free HTML CSS JS Snippet by FWD Tools"></iframe>

<p><strong>How it works:</strong> the frame's visible window is tracked in real display pixels, not a CSS transform, which keeps the reverse-mapping math clean — dividing the pan offset and frame size by the current zoom scale recovers the exact source rectangle in the image's natural coordinates. <code>drawImage()</code> then reads from that rectangle on the original, full-resolution image, so the cropped output stays sharp no matter how far zoomed the on-screen preview happened to be. Every drag is clamped so the frame can never reveal empty space at any edge.</p>

<p><strong>Best for:</strong> profile photo and avatar upload flows needing a specific aspect ratio before the file ever reaches the server. <strong>Tip:</strong> pair directly with the avatar upload editor below for a complete photo-selection-to-final-crop pipeline.</p>
