---
name: Use SVG icons for SEO use-case cards
description: Avoid text abbreviation icons in SeoSection cards; use actual SVG/icon visuals instead
type: feedback
---

When creating or updating tool page SEO use-case cards, do not use visible text abbreviations like `SORT`, `DEL`, `PDF`, `PNG`, `ZIP`, `SCAN`, or `A4` as the final card icon.

Use a real SVG/icon visual instead. The shared `SeoSection` card renderer supports mapped icon keys for common tool cards; extend that map when a new use-case icon concept is needed.

Why: Text abbreviation icons look unfinished in the UI. User explicitly asked on 2026-05-01 to replace them with SVG icons and remember this for future tools.
