The comprehensive content pass (deep-dive About text, multi-paragraph explanations, data tables, extensive FAQ sections) isn't just for organic search ranking — it also directly serves AdSense: Google's crawlers need substantial text content to understand page topic and serve relevant, higher-paying contextual ads. A page that's mostly interactive tool UI with thin surrounding text gives Google little to key ad relevance off of.

**Why:** user flagged this explicitly while reviewing the svg-wave-generator content-audit pass, confirming the multi-paragraph About + table + FAQ structure is valuable for ad monetization quality, not only SEO ranking.

**How to apply:** when weighing whether a tool page's content pass is "enough," remember the bar is both (1) organic search / user value (see [feedback_seo_content_volume](feedback_seo_content_volume.md), [feedback_seo_search_intent](feedback_seo_search_intent.md)) and (2) ad-relevance text density for AdSense. Structured content — real paragraphs, tables, FAQs — beats short bullet fragments for both goals simultaneously, so there's no tension between them; keep prioritizing genuine structured text over the bare minimum.
