Every tool page's SeoSection content must target 800–1200+ words total across all five content areas:

- **about.description**: 150–200 words — explain what the tool is, why it matters, what problem it solves, name the technology/standard it deals with, and mention related tools or frameworks it helps with
- **howToUse**: 200–250 words — full step-by-step walkthrough of every feature and panel; mention keyboard shortcuts, upload, copy, download, and edge cases
- **features**: 10 items with 10–15 words each — specific and descriptive, not just a noun
- **useCases** (6 cards): 2–3 full sentences each (~40 words), not a single short sentence
- **faqs**: 8–11 questions with 3–5 sentence answers (~60–80 words each)

**Why:** User asked for this explicitly on 2026-04-17 after seeing the JWT decoder SEO. More content volume = better Google ranking signals.

**How to apply:** Any time a new tool is created OR an existing tool page is updated, check all five sections meet these word count targets before finishing.
