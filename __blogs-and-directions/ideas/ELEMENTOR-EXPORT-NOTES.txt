HOW TO BUILD (what works)
  1. create-page (draft) -> post id.
  2. build-composition: XML of widgets with a unique configuration-id on every tag, plus three maps keyed by
     that id: element_config (widget settings), style (plain CSS string), classes (global class labels).
  3. Widgets available (V4 "atomic"): e-flexbox, e-div-block, e-grid, e-heading, e-paragraph, e-button,
     e-image, e-svg, e-divider, e-youtube, e-self-hosted-video, e-tabs (+menu/tab/content), e-accordion
     (+item/header/title/icon/content), e-background-video, e-form, e-collection-loop.
  4. Check the result: get-page-structure (add element_id + include_content=true to see saved settings and CSS),
     create-preview-link, then screenshot the signed preview URL with Playwright (headless Chromium is allowed).
     A small script that does this: take a URL, open at 1280 and 390 wide, fullPage screenshot.
  5. update-page-settings {"template": "elementor_canvas"} hides the WordPress theme header and title so only
     our section shows.

LIMITS AND QUIRKS FOUND (important, read before building)
  - Calls can TIME OUT or return ECONNRESET and still have saved. ALWAYS run get-page-structure before
    retrying, or you will create duplicates. Send one edit per call; big two-op calls dropped the connection.
  - Shorthands that are NOT saved (reported in "warnings" of the response): background-image / background with
    gradients (the three-glow hero background), pointer-events. Always read the warnings.
  - Inline style on <span> inside a heading is stripped (only tags b, strong, sup, sub, s, em, i, u, a, del,
    span, br survive, and attributes such as style are removed). So a coloured highlight word needs another
    way (try an <em> styled through the parent, a global class, or split text).
  - cqi / container-query units are not supported in this context; use vw and clamp() (media queries only as
    @media(--mobile) style breakpoints, not pixel queries).
  - Fonts: one Google Font name per font-family, no fallback stacks. Our hero used Space Grotesk and Inter.
  - Hover states work inline: "&:hover { ... }" inside the style string. Animations (animation / animation-*)
    are dropped, so our GSAP data-anim effects need separate JS or Elementor interactions
    (elementor://interactions/schema).
  - e-image with an external URL works ({"src":{"url":...,"alt":...},"size":"full"}). Whether Elementor copies
    external images into the Media Library on IMPORT of a template file is still UNTESTED. Must be tested.
  - e-svg needs an uploaded SVG attachment (external URLs render empty). Icons would need another plan.
  - Global variables and global classes on the test site are empty. Idea: create one variable per theme value
    (brand, bg, surface, text, muted, radius) so the exported kit is re-themable in one place.
  - Elementor Pro is not installed on the test site (custom CSS, theme builder, site-parts are Pro features).
  - Elementor is moving to V4 (atomic elements, classes), which is exactly what this MCP builds. Good fit,
    but formats may still change: re-test after Elementor updates.

WORKAROUNDS THAT WORK (found 2026-10-30)
  - Soft glow backgrounds: gradients are dropped, so use small absolutely positioned e-div-block elements with a
    solid rgba background-color + filter: blur(90px) (filter blur IS saved). box-shadow alone leaves a dark hole in
    the centre; a plain fill alone gives a hard disc; fill + blur gives the soft glow.
  - box-shadow: none and similar resets are not saved; remove a style by rebuilding the element.
  - Coloured highlight word inside a headline: NOT possible natively. <em> survives in the title text, but nested
    selectors in the style ("& em { ... }") are not saved. Options to test: split into h1 + styled span widget,
    a global class, or Elementor Pro custom CSS.
  - elementor_canvas page template (update-page-settings) removes the WordPress theme header/footer so only the
    section shows.
  - manage-elements: use the element ids returned by the LAST build-composition (resolved_xml); delete + update
    several elements in one call works for small edits.
